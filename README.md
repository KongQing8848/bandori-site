# 邦多利 BANDORI! · 少女乐队应援站

一个纯静态的《BanG Dream!》粉丝站：九支乐队、四十五位角色、三十首代表曲、企划时间线，还有一台「今日推し」抽卡机，以及一段用 Web Audio 实时合成的原创 BGM。

没有构建步骤，没有第三方依赖，双击 `index.html`（或起一个静态服务器）就能看。

> 音乐是实时合成的，不含任何原曲录音。浏览器要求先有一次点击才能出声：右下角的「♪ BGM」或每首歌左边的 ▶。

## 本地预览

```bash
cd bandori-site
python3 -m http.server 8099
# 浏览器打开 http://127.0.0.1:8099
```

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面骨架：首屏、乐队、成员、曲单、时间线、抽卡、弹窗 |
| `style.css` | 全部样式：黑胶唱片、均衡器、渐变卡片、滚动显现、响应式 |
| `app.js` | 数据与交互：渲染、筛选、搜索、收藏（localStorage）、弹窗、抽卡 |
| `audio.js` | 原创合成音乐：8 小节 BGM 循环 + 每首歌 4 小节乐队风格试听 |

## 想改点什么

- **加乐队 / 改配色**：`app.js` 顶部 `BANDS` 数组，`color` 决定卡片光晕、头像和曲目标签的颜色，`mark` 是卡片右下角的大字水印。
- **加成员**：`MEMBERS` 数组，`band` 填乐队 `id`，`alias` 可选（RAISE A SUILEN 与 Ave Mujica 的舞台名）。
- **加歌**：`SONGS` 数组，`tag` 会显示在右侧（代表曲 / 动画 / 单曲…）。
- **改时间线**：`TIMELINE` 数组。
- **改抽卡台词**：每个乐队的 `quote` 字段。

## 音乐

- 右下角 `♪ BGM`：108 BPM、F–G–Em–Am 的 8 小节循环，鼓 / 贝斯 / 琶音 / 铺底都是现场用振荡器合成的。
- 歌曲左侧 ▶：按乐队换速度、调式、波形和低通，生成 4 小节原创片段，不是原曲。
- 想换 BGM 的和弦或音色，改 `audio.js` 里的 `BGM_CHORDS` / `PRESETS`。
